# A2FMNLP:Weak-tie-aware attention-based adaptive fusion for multiplex network link prediction

Multiplex networks provide a framework for describing complex systems with multiple interaction patterns among the same set of entities. However, link prediction in multiplex networks remains challenging because information transferred from auxiliary layers can be either complementary or misleading, especially for weak ties that often lack strong local structural support. In this work, we propose A2FMNLP, an adaptive fusion framework for weak-tie-aware multiplex link prediction. The proposed framework separates topology-driven aggregation from node-specific semantic representation within each layer and employs directional attention with node-wise gating to selectively integrate cross-layer information. Extensive experiments on five real-world multiplex networks demonstrate that A2FMNLP consistently improves weak-tie prediction across different ways of characterizing weak ties, including community separation, attribute dissimilarity, and limited neighborhood overlap. Furthermore, controlled perturbation experiments show that the adaptive fusion mechanism is robust against noisy and mismatched cross-layer information. These results highlight the importance of selective information integration in multiplex complex networks and provide an effective approach for predicting structurally weak but functionally important connections.
